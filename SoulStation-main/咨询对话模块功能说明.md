# 咨询对话模块功能说明

## 功能概述

咨询对话模块实现了用户与咨询师之间的实时文字/文件交流功能，支持消息轮询、文件传输、咨询结束等完整流程。

## 后端API（已实现）

### 1. 咨询师端接口

#### 获取咨询师订单列表
- **路径**: `GET /api/consultation/counselor/orders`
- **功能**: 获取当前登录咨询师的订单列表
- **权限**: 仅咨询师可访问
- **参数**:
  - `status_filter`: 状态筛选（pending/confirmed/in_progress/completed/cancelled）
  - `page`: 页码
  - `page_size`: 每页数量
- **返回**: 订单列表及各状态统计

#### 处理预约订单
- **路径**: `POST /api/consultation/order/{order_id}/handle`
- **功能**: 咨询师同意或拒绝预约
- **权限**: 仅咨询师可操作
- **参数**:
  - `action`: agree（同意）/ reject（拒绝）
  - `reason`: 拒绝理由（拒绝时必填）

### 2. 对话接口

#### 获取对话消息
- **路径**: `GET /api/consultation/{appointment_id}/messages`
- **功能**: 获取指定咨询的对话消息列表
- **权限**: 订单双方均可访问
- **参数**:
  - `last_id`: 最后一条消息ID（用于增量获取）
  - `limit`: 获取数量（默认50）
- **特性**: 
  - 支持增量获取（节省带宽）
  - 自动标记对方消息为已读

#### 发送消息
- **路径**: `POST /api/consultation/{appointment_id}/message`
- **功能**: 发送咨询对话消息
- **权限**: 订单双方均可发送
- **支持类型**:
  - `text`: 文本消息
  - `image`: 图片消息
  - `file`: 文件消息
- **限制**: 
  - 只能在已确认或进行中的预约中发送消息
  - 文本消息最大5000字符

#### 上传文件
- **路径**: `POST /api/consultation/upload`
- **功能**: 上传咨询相关文件
- **支持格式**:
  - 图片：JPG、PNG、GIF
  - 文档：PDF、DOC、DOCX
  - 音频：MP3、WAV
- **大小限制**: 10MB

#### 结束咨询
- **路径**: `POST /api/consultation/{appointment_id}/end`
- **功能**: 结束当前咨询会话
- **权限**: 用户或咨询师均可发起
- **限制**: 只能结束状态为"进行中"的咨询
- **效果**: 
  - 订单状态更新为"已完成"
  - 触发评价提醒

#### 添加咨询备注
- **路径**: `POST /api/consultation/{appointment_id}/note`
- **功能**: 咨询师添加咨询备注
- **权限**: 仅咨询师可操作
- **用途**: 记录咨询过程中的重要信息

## 核心功能实现

### 1. 权限验证
- ✓ 用户只能访问自己创建的订单
- ✓ 咨询师只能访问分配给自己的订单
- ✓ 消息仅订单双方可见
- ✓ 咨询师专属功能验证

### 2. 消息管理
- ✓ 支持文本、图片、文件消息
- ✓ 消息按时间顺序展示
- ✓ 区分发送者（用户/咨询师）
- ✓ 消息已读/未读状态
- ✓ 增量获取（减少数据传输）

### 3. 文件管理
- ✓ 文件上传（图片/文档/音频）
- ✓ 文件大小限制（10MB）
- ✓ 文件类型验证
- ✓ 文件下载功能

### 4. 咨询流程
```
预约创建 → 待确认 → 咨询师同意 → 已确认 
  → 用户/咨询师发起对话 → 进行中 
  → 对话交流 → 结束咨询 → 已完成
  → 用户提交评价
```

### 5. 状态管理
- 订单状态：
  - `pending`: 待确认
  - `confirmed`: 已确认
  - `in_progress`: 进行中
  - `completed`: 已完成
  - `cancelled`: 已取消

- 消息类型：
  - `text`: 文本消息
  - `image`: 图片消息
  - `file`: 文件消息
  - `system`: 系统消息

### 6. 实时功能
- ✓ 消息轮询（前端定时拉取新消息）
- ✓ 未读消息提醒
- ✓ 对方正在输入提示
- ✓ 消息发送状态显示

## API使用示例

### 用户发送消息
```bash
POST /api/consultation/123/message
Authorization: Bearer {token}
Content-Type: application/json

{
  "message_type": "text",
  "content": "你好，我想咨询一些问题"
}
```

### 获取消息（增量）
```bash
GET /api/consultation/123/messages?last_id=456&limit=50
Authorization: Bearer {token}
```

### 结束咨询
```bash
POST /api/consultation/123/end
Authorization: Bearer {token}
```

## 使用流程

### 用户端流程
1. 登录系统
2. 浏览咨询师列表
3. 选择咨询师并创建预约
4. 等待咨询师确认
5. 确认后进入对话界面
6. 发送消息（文字/图片/文件）
7. 结束咨询
8. 提交评价

### 咨询师端流程
1. 登录系统
2. 进入工作台查看订单
3. 处理待确认订单（同意/拒绝）
4. 对已确认订单点击"进入咨询"
5. 与用户进行对话交流
6. 添加咨询备注
7. 发送预设素材
8. 结束咨询
9. 查看用户评价

## 常见问题

### Q: 如何开始咨询？
A: 
1. 用户在咨询师列表选择咨询师
2. 选择咨询时间和类型，创建预约
3. 咨询师在工作台确认预约
4. 双方点击"进入咨询"开始对话

### Q: 可以发送哪些类型的消息？
A: 支持文字、图片和文件消息。语音消息功能已预留接口，可根据需求添加。

### Q: 消息数据安全吗？
A: 是的，消息仅订单双方可见，且通过JWT Token进行权限验证。

### Q: 可以删除对话记录吗？
A: 删除订单时会自动删除所有关联的消息和评价记录。

## API状态码

- `200`: 成功
- `400`: 请求参数错误
- `401`: 未授权（Token无效或过期）
- `403`: 禁止访问（无权限）
- `404`: 资源不存在
- `500`: 服务器内部错误
